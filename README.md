# PrinceMix

An experimental vocal-and-beat mixer and stereo mastering plugin for Adobe Audition.

The complete editable C++/JUCE project is in **PrinceMix-0.1-Source.zip**. Extract it for local development. The GitHub Actions workflow builds universal Mac VST3, AU, and standalone versions from this source archive and packages an installer.

This is an alpha. DSP tests pass on Linux; native Mac and Audition validation is in progress. RMS-based leveling and sample-peak limiting are not LUFS or true-peak mastering.

See the README and verification notes inside the source archive for usage, limitations, and dependency licensing.
